# Glossary

| Word | Meaning |
|---|---|
| **Address** | The first DMX channel a light listens to (1–512). Set on the light itself, and in the Patch tab. |
| **Art-Net** | A way of sending DMX over a network cable. Most lighting nodes understand it. |
| **Blackout** | All lights off, without changing anything else. Tap again to bring them back. |
| **BPM** | Beats per minute: the tempo. Effects follow it. |
| **Busking** | Making up the lighting live, instead of pre-programming it. |
| **Click** | The metronome the band hears in their in-ears. |
| **Count-in** | Clicks before the music starts, so the band comes in together. |
| **Cue** | One step in the GO list. |
| **DMX** | The signal lighting uses: up to 512 channels per cable (universe). |
| **Effect** | Movement over time: a chase, a pulse, a circle for moving heads. |
| **Fade** | How long a change takes, in seconds. |
| **Fixture** | One light. |
| **Fixture type** (profile) | The list of a light's channels (dimmer, red, green, blue, pan…). |
| **Flash** | Full brightness while a button is held. |
| **Follow mode** | Manual / Hybrid / Auto: how much the tracks are in charge. |
| **GDTF** | A file describing a fixture type; manufacturers publish them. |
| **Group** | A named set of lights, e.g. *Front wash*. |
| **Guide cue** | A spoken "Verse", "Chorus" that the band hears a bar before a section. |
| **Hold** | Ignore the tracks until it's pressed again. |
| **IAC Driver** | The Mac's built-in virtual MIDI cable, between apps on the same Mac. |
| **Look** | A saved whole-stage state, used by song sections and service parts. |
| **Master** | The overall brightness slider. |
| **MIDI** | Messages between music gear and apps. The tracks send MIDI notes to move the lights. |
| **MIDI clock** | MIDI tempo messages; keyboards and pedals can follow them. |
| **Moving head** | A light that can pan, tilt and often zoom. |
| **MTC (MIDI timecode)** | A running clock (hours:minutes:seconds:frames) sent over MIDI. |
| **MVR** | A file with a whole rig: lights, positions, addresses. |
| **Node** | A box that turns Art-Net or sACN from the network into DMX cables. |
| **OSC** | Network messages from apps like Companion (Stream Deck), TouchOSC or QLab. |
| **Pad** | A live button that runs an effect, a preset or a flash. |
| **Palette (P / S / T)** | The song's primary, secondary and tertiary colours. |
| **Panic** | Hold for 1 s: stop everything live and go back to the safe look. |
| **Patch** | Telling the app which lights you have and their addresses. |
| **Preset** | A reusable colour, position, dimmer or beam setting. |
| **Programmer** | What you're editing on the Program tab; it's on top until cleared. |
| **sACN (E1.31)** | Another way of sending DMX over a network. |
| **Scene** | A button that adds lights on top of whatever is running. |
| **Section** | A part of a song: Intro, Verse, Chorus, Bridge… |
| **Service part** | Worship, Hosting, Sermon, Video, Baptism…: what drives the lights during that part of the service. |
| **Snapshot** | A saved copy of the whole show you can go back to. |
| **Stem** | One track of a song's backing tracks (drums, bass, keys, click…). |
| **Strobe** | Fast flashing. |
| **Timecode** | See MTC. |
| **Tracking** | Cues only store what changes; everything else carries on from earlier cues. |
| **Universe** | One set of 512 DMX channels, one cable or network stream. |
| **USB-DMX** | A box that sends DMX from the computer's USB port. |
