Looks

A look is a whole-stage state that sections use, such as "Verse", "Chorus" or "Bridge build". Set the lights on the Program tab, then record. If you improve a look, every song that uses it gets the change. A section whose name matches a look ("Verse 2" → "Verse") picks it automatically.

Fixture types

New fixture type

Words: dim red green blue white amber uv pan tilt zoom focus strobe haze fan. Add .fine for a 16-bit fine channel (pan.fine), =n for a default value (strobe=0), a number for a fixed value (255), or - for an unused channel. Copy the order from your light's manual.

Output

On a Mac, find the device with ls /dev/cu.usbserial* in Terminal. Simple "Open DMX" cables are not supported.

MIDI from Playback / Ableton

By default, note C1 (36) triggers a song's first section, the next note its second, and so on. Or use Learn in the song editor to map whatever your track app sends.
