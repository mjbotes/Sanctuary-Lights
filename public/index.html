Looks

A look is a whole-stage state that sections use, such as "Verse", "Chorus" or "Bridge build". Set the lights on the Program tab, then record. If you improve a look, every song that uses it gets the change. A section whose name matches a look ("Verse 2" → "Verse") picks it automatically.

Fixture types

Get your lights' files from gdtf-share.com (GDTF) or open-fixture-library.org (download "OFL JSON"). They bring the right channels, colour wheels, gobos and shutter settings.

New fixture type

Words: dim red green blue white amber uv pan tilt zoom focus strobe haze fan. Add .fine for a 16-bit fine channel (pan.fine), =n for a default value (strobe=0), a number for a fixed value (255), or - for an unused channel. Copy the order from your light's manual.

3D stage & rig

Screens & LED walls

Place your screens where they are in the room. They show the live ProPresenter slide, and lights whose beams would land on them turn red (or switch off; see Setup).

Stage size (metres)

Used for the simple stage block when no 3D model is loaded.

3D models

GLB (glTF binary) works best: export it from SketchUp, Blender, Vectorworks or most 3D tools. An MVR file from a console or CAD program brings in the whole rig: lights, positions, DMX addresses and the stage.

Output

Plug it in and tick the box: it is found automatically, and reconnects if it is unplugged. No driver is needed on a Mac (macOS has the FTDI driver built in); Windows installs it through Windows Update. Not supported: simple "Open DMX" cables and uDMX sticks. Use an Art-Net or sACN node for those.

MIDI from Playback / Ableton

By default, note C1 (36) triggers a song's first section, the next note its second, and so on. Or use Learn in the song editor to map whatever your track app sends.

OSC addresses
/sl/go · /sl/backCue list GO / back
/sl/next · /sl/prevNext / previous song section
/sl/section "Chorus" or /sl/section/chorusGo to a section of the current song (name or number)
/sl/song "Name" · /sl/song 3Pick a song
/sl/look "Name" · /sl/cue 2Show a look / go to a cue
/sl/scene "Pulpit" [0..1]Toggle a scene, or set its level
/sl/pad 3 [1|0] · /sl/pad/qPress / release a pad (number, key or name)
/sl/gm 0.8 · /sl/blackout 1Master level / blackout
/sl/strobe 1|0 · /sl/flash 1|0Strobe / flash all while 1
/sl/tap · /sl/bpm 120Tempo
/sl/mode hybrid · /sl/hold 1 · /sl/releaseFollow mode, hold, release live changes
/sl/part "Sermon"Switch the service part (Worship, Hosting, Sermon, Video…)
/sl/palette/primary "#ff8800" (or r g b 0..1)Change a palette colour for this song (until the song changes)
/sl/group/Back wash/level 0.5Group fader
/sl/group/Back wash/color "secondary"Group colour: primary / secondary / tertiary, "#rrggbb", r g b, or nothing to release
/sl/group/Back wash/fx "Chase" · /sl/group/Back wash/flash 1Group effect (by name; nothing = off) / flash

Buttons that send 1 on press and 0 on release work as expected. Any other OSC message can trigger a song section with Learn in the song editor.

ProPresenter

In ProPresenter: Settings → Network → tick Enable Network and note the port. Both computers must be on the same network (or use localhost on the same Mac). Colour sync sets the live colour of the groups ticked above (all groups if none).
